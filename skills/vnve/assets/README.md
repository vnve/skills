# 内置素材

随 Skill 离线安装。用户没有素材时可建议试用，用户选择后才导入 workspace。

- `character/`：16 位人物，每人包含默认、开心、悲伤、愤怒、惊讶五种表情。
- `background/`：20 类地点，共 56 张图片，包含默认、黄昏、夜晚、雨天、闭馆后等变体。
- `bgm/`：10 首配乐。
- `sfx/`：41 个音效及环境音。

人物与背景统一采用「清透日系动画」风格：细线稿、清晰赛璐璐阴影与明亮蓝灰配色。人物保留各自的身份特征、发型、服装和配饰，采用头部端正、平视、身体直立、双臂自然垂放的基础站姿；五种表情以同一母版编辑眉眼与嘴部。背景保留各地点的建筑、家具布局与视角，时间和天气变体以同一地点的新默认图为基准，雨天室内不添加降雨。沿用全部原有名称与路径，人物为 640×960 透明 WebP，背景为 1920×1080 WebP。

`manifest.json` 仅列出实际存在的媒体，并提供中文变体说明。manifest.json 的 audio 保留逐项作者、许可、来源、实际字节数与 SHA-256。

从本 Skill 安装目录定位文件，通过 import 接口导入选中的媒体；人物身份与媒体独立，替换图片不改变台词、声音或站位。导入格式见 [素材说明](../references/media.md)。校园、都市保留在人物和地点名称中，不再拆分主题包。

按 manifest.json 选择需要的文件，再用 `vnve inspect /absolute/workspace PROJECT_ID --brief` 获取目标组和外观的实际 ID，临时生成导入 JSON。支持一次导入多个文件，批量格式见素材说明；音频导入只登记共享库，播放安排需另行编排。

图片采用 WebP，人物保留透明通道；音频采用 Ogg/Opus。发布前应核实图片再分发授权。音频许可沿用清单中的逐项记录；循环点和音量需按实际使用检查。
